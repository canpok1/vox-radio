# [C] 演出プロンプト（SE挿入位置の判定・読み変換・抑揚付与）

以下のコーナー別セリフ列と使用可能なSE（効果音）一覧を元に、SE の挿入位置と間（pause）を判定し、VOICEVOX 音声合成向けに各セリフの読み変換テキストを生成し、さらに各セリフの抑揚（intonation・pitch・speed）を付与してください。

BGM とジングル（開始・終了）はコーナー毎の profile 設定により決定的に挿入されます。ここでは SE と間のみを判定してください。

## 番組全体の演出方針

{{program_direction}}

`（なし）` の場合は番組全体の演出方針指示は存在しません。

## コーナー別セリフ列

```json
{{corners}}
```

各コーナーのフィールド:
- `title`: コーナー名
- `direction`（省略可）: このコーナーの演出意図（SE・pauseの挿入タイミングに関する指示）。**挿入位置の判断に積極的に活用すること**
- `lines`: セリフの配列（インデックスは0始まり）

## 使用可能なSE一覧

```json
{{asset_catalog}}
```

SEリストのフィールド:
- `name`: アセットキー名（挿入時に `asset_name` へ指定する値）
- `description`: アセットの説明（省略可）。何の音か・どんな場面で使うかを記述。**挿入タイミングを判断する際はこの説明を参考にすること**

{{preset_info}}

## 各アセットタイプの挿入ルール

### 間（pause）
- オチの前の溜め、しんみりした余韻など、**意図的な空白**が演出として必要な場合のみ使用する
- 指定コーナーの `after_line_index` のセリフの直後に指定秒数の無音が入る（BGMは途切れず継続）
- `duration_sec` は **0.3〜2.0秒** を目安とし、最大5.0秒まで指定可能
- 過剰な「間」は dead air になるため、**全体で0〜2回まで**を目安に控えめに使う
- 通常のトーク進行・セリフの切れ目には使わない（デフォルトのポーズで十分）

### SE（効果音）
- トピックの転換点など、効果的な場所にのみ挿入する
- 使いすぎると煩わしくなるので、厳選して挿入する（全体で0〜3回程度）
- 指定コーナーの `after_line_index` のセリフの直後に再生される（overlayのため本編と同時）

## 読み変換ルール（line_conversions）

`line_conversions` には各セリフの VOICEVOX 読み変換テキストを生成してください。

- **全セリフを変換対象にする** — 変換不要なセリフも含め、全ての `line_index` に対して変換エントリを出力してください（欠落したセリフは元テキストにフォールバックされます）
- **セリフの内容・意味・件数・話者を変えない** — 表記のみ変更し、セリフの順序も変えない
- **漢字は元表記のまま残す** — 漢字の読み推定は VOICEVOX(OpenJTalk) に委ねるため、かな化・カタカナ化はしない
- **助詞のかな置換（wa/e化）はひらがなのまま** — 助詞の「は」は「わ」、助詞の「へ」は「え」とひらがなで書く（発音どおりに表記する）。**助詞はカタカナにしない**（カタカナ「ハ/ヘ」だと ha/he と読まれ助詞が壊れる）
  - 例: 私は→私わ、これは→これわ、学校へ行く→学校え行く
  - 連語末尾の助詞も対象: では→でわ、には→にわ、とは→とわ、ては→てわ、へは→えわ 等
  - **語の一部の「は」「へ」は助詞ではない**（置換しない・漢字のまま残す）— 例: 話す・部屋・葉・母・平和
- **英単語・英語ファイル名** — 発音を表す日本語に置き換える。拡張子も省略しない（例: `README.md`→リードミードットエムディー、`merge`→マージ）
- **ファイルパス・URL・UUID 等の長い文字列** — セリフに含めない

## 抑揚パラメータの付与（line_voices）

`line_voices` には各セリフの抑揚（`intonation`）・音高（`pitch`）・話速（`speed`）を指定してください。

- **全セリフを対象にする** — 全ての `line_index` に対してエントリを出力してください（欠落したセリフは VOICEVOX のデフォルト設定で合成されます）
- **値は「利用可能な音声プリセット」に列挙された名前から選ぶ** — 一覧にない名前は指定しないでください
- **`intonation` は必須です** — 全エントリで指定してください。`pitch` / `speed` は感情や文脈に合うものがなければ省略してかまいません（省略時はデフォルトで合成されます）
- **セリフは1文ごとに分割済みです。同一話者の連続セリフでも、感情・テンションが変わる境目では値を変えてください**（例: 失敗談を語る文は「控えめ」、気を取り直して前を向く文は「表現豊か」）
- **話題・感情が変わらない範囲では同じ値を維持し、不自然な乱高下は避けてください**

## 注意事項

- `corner_index` は0始まりのコーナーインデックスです（コーナー別セリフ列の配列インデックスと一致）
- `after_line_index` は各コーナー内での0始まりのセリフインデックスです（**コーナーをまたいだ通し番号ではありません**）
- `line_conversions` / `line_voices` の `line_index` も各コーナー内での0始まりのセリフインデックスです（コーナーをまたいだ通し番号ではありません）
- `asset_name` は対応するSE一覧のキー名を使用してください
- 挿入が不要な場合は `insertions` / `pause_insertions` をそれぞれ空配列にしてください
- 同一コーナー・同一 `after_line_index` に SE と pause が両方ある場合、SE → pause の順で再生されます
